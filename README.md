# Rule-Based-Chatbot
A simple rule-based chatbot built using Python that responds to user input using if-elif-else conditions and loops.
# 🤖 Rule-Based Chatbot

## 📌 Project Overview
This project is a simple Rule-Based Chatbot developed using Python. The chatbot interacts with users by responding to predefined commands using conditional statements (`if`, `elif`, `else`) and a `while` loop. It is designed to demonstrate basic Python programming concepts and conversational logic.

## ✨ Features
- Greets the user
- Responds to "hello" and "hi"
- Provides help information
- Answers basic questions about AI and Python
- Responds to "thanks"
- Greets with "Good Morning" and "Good Night"
- Ends the conversation when the user types "bye"

## 🛠️ Technologies Used

- Pydroid 3 (Android IDE)

## ▶️ How to Run
1. Install Python or Pydroid 3.
2. Open `Rule_Based_Chatbot.py`.
3. Run the program.
4. Enter your name.
5. Start chatting with the bot.
6. Type `bye` to exit.
