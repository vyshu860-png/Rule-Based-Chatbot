
🤖 Sam AI – Rule-Based Chatbot

📌 Project Description

Sam AI is a simple and interactive rule-based chatbot developed using Python. It provides users with quick responses to common questions through a user-friendly Streamlit web interface.

The application is developed and tested using Google Colab, while Ngrok is used to create a public URL for accessing the chatbot.

🎯 Objective

The main objective of this project is to build a simple AI chatbot that can understand basic user questions and provide predefined responses.

🛠️ Technologies Used

- Python – Chatbot development and logic
- Streamlit – Interactive web interface
- Ngrok – Public URL/tunneling
- Google Colab – Development and execution environment
- Rule-Based AI – Predefined responses based on user input

✨ Features

- 💬 Interactive chatbot
- 🤖 Rule-based AI responses
- 🌐 Streamlit web interface
- 🔗 Public access using Ngrok
- ⚡ Quick responses
- 😊 Simple and user-friendly interface
- ❓ Help option for supported questions

User: Tell me a joke

⚙️ How It Works

1. The user enters a question in the Streamlit chatbot interface.
2. The application receives the user's input.
3. The chatbot checks the input against predefined rules and keywords.
4. A suitable response is selected.
5. The response is displayed in the Streamlit interface.
6. Ngrok provides a public URL to access the application.

🚀 How to Run

1. Install Required Libraries

pip install streamlit pyngrok

2. Run the Streamlit Application

streamlit run app.py

3. Start Ngrok

Configure Ngrok and create a tunnel to the Streamlit port.

The generated public URL can then be opened in a web browser to use Sam AI.
